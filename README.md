# LIAR Vóley

Contador de sets y apuestas entre capitanes. HTML, CSS y JavaScript puro, sin instalación.

## Correr en Visual Studio Code
1. Abre la carpeta `liar-voley` (Archivo > Abrir carpeta).
2. Instala la extensión **Live Server**.
3. Clic derecho en `index.html` > **Open with Live Server**.

Para verla en tu celular mientras programas, conéctalo al mismo WiFi y abre `http://IP-DE-TU-PC:5500`.

## Publicar en Vercel
1. Sube la carpeta a un repositorio de GitHub.
2. En vercel.com: **Add New > Project**, elige el repositorio y pulsa **Deploy**. No requiere configuración.

## Archivos
- `index.html`: estructura
- `styles.css`: diseño responsive
- `app.js`: lógica y datos (se guardan en el navegador con localStorage)
